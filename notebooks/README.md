# Offline walkthroughs
Run `make setup && make notebooks` from the repository root to execute and save both notebooks with optional Jupyter packages; no keys, paid calls or private corpus are needed.
[Data and EDA](01_data_and_eda.ipynb) validates the committed store and two findings; [evaluation](02_evaluation_walkthrough.ipynb) recomputes saved headline metrics and intervals, with reproduction limits stated in each notebook.
