## Reproduction and acceptance boundaries

The notebooks use the committed processed statistics, scores and metrics, not private report text, API keys or paid calls. They reproduce existing EDA findings and two-run intervals rather than create new experiments. Development and original-test second-run paired files declare incomplete data; the evaluation notebook displays that limitation and independently validates split-matched score rows for the headline. Frozen files are unchanged.

A fresh clone cannot rerun report retrieval, source extraction or source-text rights clearance without separately acquired local material. Notebook/test execution is not evidence that publisher rights, provider terms, policy accuracy or production controls are settled. See the [data sheet](data-sheet.md#9-open-licence-items-and-what-the-rights-scan-covers), [system card](system-card.md#limitations) and [requirements matrix](requirements-matrix.md#owner-acceptance-checkpoint) for remaining acceptance work.
