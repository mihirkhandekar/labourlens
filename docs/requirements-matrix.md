# Requirement-to-evidence matrix

Updated 30 October 2026. The binding source is `Tech Challenge - GenAI Engineer v1.0.pdf`, Section 1 core requirements, minimum demonstration scenarios and submission requirements, plus Section 2 innovation assessment. The original mapping is in [requirements and scope](01_REQUIREMENTS_AND_SCOPE.md).

**Status:** `done` means the stated acceptance criteria have recorded evidence; `partial` means implementation or documentation exists but acceptance work remains; `not started` means no relevant implementation evidence exists. Code paths establish implementation, not a passing test result. Saved reports establish only the configuration and corpus they describe. This documentation refresh did not run tests, build the application, fetch sources or execute evaluation.

**Review boundary:** the [live gold file](../experiments/gold/draft_cases.jsonl) contains **268 draft cases: 237 development and 31 held-out**. Gold drafting and three AI review rounds are recorded in [gold history](../experiments/gold/CHANGELOG.md) and its linked review directories. **No human review has been completed.** Owner review, gold freeze and a held-out run remain pending. AI pre-review and model judging do not satisfy the assessment's human-review requirement.
