## 3. Verified OK

- Hash verification: `check_manifest` re-hashes every raw file against the manifest on each build; observed 85/85 pass. Signed S3 query strings are stripped (`redact_url`) and `no_signed_url_material` passes over the manifest and history.
- Immutability/additivity: pre-v3 manifest (79 entries) identical to the v3 manifest for those entries; history file has 85 lines, one per source; `tests/data` including corpus tests: 92 passed. `determinism-v3.json`: 52 files byte-identical across two builds.
- Host allow-list: https only, redirect off-list fails; MTI page host not allowed (only the PDF host).
- Rights: `.gitignore` excludes `data/raw/`, `data/passages/`, `data/index/`, `data/runs/`, `data/audit/`; no PDF is tracked; all 16,419 passages have `commit_text=False`. A 10-word shingle scan of tracked text files against all passages found overlap only in specs (dataset definitions), manifest copyright notices, one sources.json title and one gold AI-review line; at 7 words the hits are in gold cases, dense-experiment case files (`experiments/runs/dev-dense-E5/*.cases.jsonl`, 25-37 hits each), `docs/human-review/gold-review.md` and `ai-adjudication.md`, i.e. short quoted evidence snippets that likely exceed the "no extended MOM text" intent of D-001 and should be eyeballed (INFERENCE: not judged as a breach). No committed MOM/MTI passage text beyond that. MOM wage reports' all-rights-reserved notice is present in the fetched PDFs (page 2); the MTI file has no such notice, so `unresolved` is correct.
- Labelling: no indicator mixes units; population and adjustment vary only where the publisher gives both (unemployment rate: 3 populations, 2 adjustments, each row labelled); new datasets carry unit, population (`not_applicable` or `employees`) and `adjustment=unspecified`; missing tokens `na` become null with `missing_reason`, never zero (ULC 1,200 and VA 864 null cells, all pre-2005/2009, none in answer scope, `in_scope_values_present` passes).
- Scope: new tables give 10 in-scope quarters per series (510 in-scope rows) and exact first/last periods are enforced.
- Preliminary vs final: `release_stage` is carried on every passage; reconciliation keeps advance, final and dataset values as separate fields with passage/observation ids; the interpretation note flags the MDW explanation as an inference.
- EDA numbers re-computed from the parquet: ratio peak 2.55 in 2022-Q2, 1.48 in 2026-Q2; resident SA rate range 2.6-2.9; retrenchments 3,830 -> 4,620 (+20.6%).
- Sector hierarchy of the new tables is parsed into `sector_path`/`sector_level` (4 levels), and parent/child sums are explicitly not asserted.
