## 9. Five things to keep

1. Action titles with computed numbers. Titles and takeaways are generated from `report.json` in code (for example `ch2-data.js` `refresh()` rewrites each title from the visible window), so a number on screen cannot drift from the data.
2. Chart accessibility and honesty devices: every figure has a "View data table" toggle with a real `<table>`, a hidden text summary for screen readers, keyboard-navigable tooltips, intervals drawn as whiskers, and reduced-motion handling. No scroll listeners; reveal uses `IntersectionObserver`.
3. Definition discipline in the interface: the home explorer refuses to mix units, the unemployment chart labels population and adjustment per series, and the "Do not mix adjusted and unadjusted rates" takeaway sits next to the chart. This is the CLAUDE.md data rule expressed as UI.
4. Workbench answer states: plain status badges (Answered, Abstained, Needs clarification, Refused) with a one-line meaning, citation chips that turn dashed red when a label has no matching evidence, and an evidence drawer with the exact excerpt and source link.
5. The agent stepper in the Agent chapter: a controllable replay of a recorded run with node and edge highlighting, one stated limitation (statistics-only smoke run), and keyboard access. It is the right model for the rebuilt deck's own controls.

## 11. Implications for the presentation rebuild

- Keep the information architecture: Overview, Presentation, Workbench; keep every number sourced from `report.json`.
- The deck should be one slide per screen (`min-height: 100dvh`), Previous and Next buttons plus arrow keys, a thin progress line and "n / N" counter, `prefers-reduced-motion` honoured, no scroll listeners. Motion that is motivated: slide-to-slide translate and fade, chart series drawing in, number count-up only where the number is the point of the slide.
- Slide register: action title with a number, three terse bullets maximum, one figure. No eyebrow, no ghost numerals, no provenance chips on the slide face. Sources open from a per-slide disclosure.
- Move to the Limits slide: every hedge now repeated across chapters. Move to speaker notes or `study/`: the Questions slide.
- Dependencies, if any (icons, a motion helper), must be vendored under `web/static/vendor/` with a licence file; none is required for the deck itself.
